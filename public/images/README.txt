Drop any photo here (jpg, png, webp) and it becomes usable in your site
immediately at the path:  /images/your-filename.jpg

Example: if you add a file called "site-visit.jpg" to this folder, you can
show it anywhere in App.jsx with:

  <img src="/images/site-visit.jpg" alt="Site visit" className="rounded-xl w-full" />

No import statements needed, no build step required to "register" the image —
just drop the file in and reference its name.
